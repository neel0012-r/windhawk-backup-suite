# 🦅 Windhawk Backup Suite

**A faster, easier way to backup your Windhawk mods and share your customizations with others.**

Windhawk Backup Suite is a lightweight, high-performance Windows tool built in pure C++ that lets you create complete snapshots of your installed Windhawk mods, configurations, and source files into portable archives with just a few clicks.

## 🚀 Why Windhawk Backup Suite?

- **⚡ Fast, One-Click Backup:** Instantly bundle your installed mods, custom settings, and tweaks into a portable `.zip` archive.
- **🤝 Easy Mod Sharing:** Want to share your desktop setup, taskbar themes, or tweak configurations with friends or the community? Just export and send them your backup zip.
- **📥 Selective Restoration:** When importing a backup, choose exactly which mods you want to install and which ones to skip.
- **🔄 Automatic Engine Refresh:** Automatically reloads Windhawk so your imported mods and configurations apply immediately.
- **🛡️ Safe & Offline:** Backs up your local mod source code (`.wh.cpp`) and registry preferences directly on your PC with zero cloud tracking.
- **📦 100% Portable:** Single standalone `.exe` (~1.6 MB) with zero installers or extra dependencies. Run it from anywhere or carry it on a USB drive.

---

## 📥 How to Download & Run

1. Go to the **[Releases](../../releases)** tab on the right side of this repository.
2. Download **`WindhawkBackupSuite.exe`**.
3. Double-click to run — no installation required!

---

## 🛠️ How to Build from Source

Requirements: Windows 10/11 and Windhawk compiler (or Clang / MinGW).

1. Clone or download this repository.
2. Run `build.bat` in the root folder.
3. The standalone executable `WindhawkBackupSuite.exe` will be built automatically.
